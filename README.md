## v6.4 導入・追い抜き・横持ちHUD
- 序盤30秒は成功体験を優先。開始480mは岩なし、最初2,500mは岩同士を450m以上離し、中央を広く確保。導入中は1衝突最大5ダメージ（v6.5の耐久補正後）、30〜40秒で通常の危険度へ移行。
- A長押しによる実際の連続6漕ぎと、波の山での漕ぎによる波乗りを導入。達成時に短いフィードバックを出す。何も操作せず成功した扱いにはしない。
- 追い抜きは速度線・短いズーム・上昇音・順位バウンド。抜かれた時は短い減光と小さい下降音。
- 速度30〜130の実際の範囲でFOVを約61〜79度へ変化。速度とエンジンに連動する風音・画面端のラインを追加し、中央の視野は空ける。
- スマホ横画面は距離/人数/HP/体力を上端の細い帯、順位/時間と速度を小型化。タイトル、重複ガイド、船名タグを畳む。落水者の目印と危険警告は残す。
- `node tools/test_raceflow.cjs`：既存27＋7＝34項目。全3コース×6船種で4fps相当の更新間隔を模した最初6秒/30秒の生存、長押し漕ぎと波乗り、通常難易度への復帰、実際の追い抜き判定などを確認。これは実機のGPU速度測定ではない。

## v6.3 入力・衝突・船と乗組員
- iOS対策：ゲーム中のcanvasと操作領域にtouch-action:none。Touch/Gestureイベントは既定動作だけを抑制し、操作はPointer Eventsに一本化。二重クリックや合成clickを漕ぎ操作へ流さない。
- 押下時に即座に沈み込み・発光・短い音。漕ぎの最短間隔は240msから100msへ。衝突後の回復減速中も入力を受付。体力消費、減速優先、長押し漕ぎは維持。
- 十字パッドは押下時の境界をキャッシュし、移動ごとのレイアウト読みを廃止。Pointercancel・blur・resizeを処理。
- 岩の接触点から約120〜170の飛沫、木片・石片、水面の波紋を固定数のプールで表示。衝突は横方向の押し返し、短い後退と船体のひねり、速度低下を伴う。
- 衝突音は破裂音・低音・木材の軋み・水音を合成。音OFFに従い、既存のマスター音量とコンプレッサーを通す。振動APIは対応端末だけで使用し、iOSの振動は保証しない。
- 濡れた船体と木目/PVCの微細な凹凸、滑らかなゴム艇の陰影、係留ロープ・持ち手・継ぎ目・コックピットを追加。装飾は材質ごとにまとめ、船体の外周・当たり判定を維持。
- 人間は複数の肌色・頭の形・服の色を持ち、少数の異星人を混在。外見と性格・能力を結びつけない。全種が救命装備を着用。
- リアクション13状態：巡航、衝突、着水、安堵、加速、踏ん張り、減速、渦、危険察知、落下、競り合い、漕ぎ、歓喜。乗客の腕は実際の長さでIKを解く。漕ぎ手はグリップとの整合を優先。
- 検証：`node tools/test_response.cjs`（既存17＋追加10＝27項目）。iPhone実機はNOT_TESTED。実測の入力遅延・ネイティブのダブルタップ挙動は未確認。

下部は操作専用。画面の25%または操作サイズに必要な高さを確保。ボタンは押下時に沈み、音ONなら短い矩形波クリックが鳴る。

## 岩礁の当たり判定（v6.1）
船種別の固定半径を廃止。船体メッシュの外周、表示倍率1.2、旋回角を使います。和舟のプレイヤー艇は従来と別の実メッシュを使用。船首・船尾・側面、岸との接触、高速・横移動中の通過を判定し、オールや乗客は判定に含めません。船幅による通れる隙間の差は残します。

## 流される加速エンジン（v6.2）
金色のエンジンを取ると2秒だけ通常速度の2倍。最大4個/コース、数十秒ごとに遭遇する疎な配置。水流で移動し、CPUと取り合います。時間延長・重複なし、終了後6秒は再取得不可。Bまたは岩・岸への衝突で解除。耐久回復・無敵はありません。大落差・大渦の接近地点では出さず、安全な配置を選べない枠は出現させません。

## EXTREME
従来の目標流速を3.25倍に設定。狭窄と勾配による追加加速、カーブ外側への慣性、立ち波、渦を反映。速度はゲーム内演出値で、実河川の測定速度ではありません。
危険に進路が重なると、岩または着水までの秒数と対処を表示。岩との高速衝突は重傷、大落差は踏ん張らなければ一撃で失敗する場合があります。
3コース各11,375ゲーム内m・12区間・5落差。自動操船のシミュレーションでは約170〜173秒。TOURINGは×1で、所要時間も長くなります。
